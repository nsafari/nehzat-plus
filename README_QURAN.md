## ⚙️ پیش‌نیازهای فنی (TECHNICAL REQUIREMENTS)

### حداقل (فیزیکی/کاغذی) - سال ۱
- پرینت تمام فرم‌ها (A4، دوطرفه)
- پرونده‌های کاغذی پرونده_بندی (یک پرونده در هم‌رنگ برای هر دانش‌آموز)
- دفاترچه گزارش ماهانه برای مربیان
- فایل‌های صوتی روی فلش/هارد محلی

### پیشرفته (هیبرید) - سال ۲
- اسکن ماهانه پرونده‌ها → کلود (Google Drive/Nextcloud)
- اشتراک‌گذاری لینک پرونده با والدین (Read-only)
- داشبورد Excel/Google Sheets برای KPIها
- فرم‌های Google Forms برای نظرسنجی‌ها

### کامل (دیجیتال بومی) - سال ۳+
- اپلیکیشن/پورتال (React Native / Flutter / PWA)
- دیتابیس PostgreSQL + Supabase/Firebase
- احراز هویت: OTP + نقش‌های RBAC
- اعلان‌ها: Push/PWA/ایمیل/پیامک
- بک‌آپ خودکار، رمزنگاری AES-256

## 🔐 امنیت و حریم خصوصی (SECURITY & PRIVACY)

| اصل | پیاده‌سازی |
|-----|-----------|
| **حداقل داده** | فقط اطلاعات لازم برای اجرا |
| **مالکیت دانش‌آموز** | دانش‌آموز/والدین مالک پرونده‌اند |
| **دسترسی بر اساس نقش** | RBAC: دانش‌آموز > مربی > والدین > مدیر > تحلیلگر |
| **رمزنگاری** | AES-256 در حال انتقال و در حالت بیکار |
| **لاگ دسترسی** | تمام خواندن/نوشتن ثبت شود |
| **حق فراموشی** | حذف حساب با حفظ آرشیو قانونی |
| **مقررات ایران** | قانون حمایت داده‌های شخصی، مقررات اطلاعاتی |
