## ۱.۰ تقویم اجرایی سالانه مکتب (۱۴۰۳–۱۴۰۴)

| ماه | رویداد اصلی | مخاطب |
|-----|------------|-------|
| شهریور | ثبتنام + جلسه اولیا و مربیان آغاز سال | همه |
| مهر | شروع ترم ۱ (هفتههای ۱–۸) | همه |
| آبان | ارزشیابی نیمترم ۱ + جشن کوچک | همه |
| آذر | ادامه ترم ۱ + مناسبتهای محرم/صفر (درس عاشورا) | حلقه ۳+ |
| دی | ارزشیابی پایانی ترم ۱ + جلسه اولیا | همه |
| بهمن | شروع ترم ۲ + دهه فجر (مسابقه انقلاب و دین) | حلقه ۵+ |
| اسفند | میلاد پیامبر (ص) — جشن + مسابقه قصهگویی | همه |
| فروردین | تعطیلات + تکلیف نوروزی (قرآن و خانواده) | همه |

| مرداد | ارزشیابی پایانی سال + جشن فارغالتحصیلی | حلقه ۷ + همه |

## ۲.۰ نمونه جلسه کامل — نوآموزان (۴–۶ سال) — ۱۲۰ دقیقه

| زمان | بخش | فعالیت | هدف |
|------|-----|--------|-----|
| ۰–۱۰ | ورود و بازی آزاد | بازی «اسم من» با توپ | انس و شادی |
| ۱۰–۲۰ | سلام و حضور | سرود «سلام به خدا» + دعای شروع | شروع معنوی |
| ۲۰–۴۰ | قصهگویی | قصه «حضرت علیاصغر (ع)» با عروسک و تصویر | محبت به اهل بیت |
| ۴۰–۵۵ | بازی حرکتی | بازی «سجده کوچک» (حرکت و تکرار ذکر) | انس با عبادت |
| ۵۵–۷۰ | میانوعده + تشکر | خوردن میانوعده با «بسم الله» و «الحمدلله» | شکرگزاری عملی |
| ۷۰–۹۰ | حفظ سوره با بازی | سوره کوثر با آهنگ + حرکات دست + بازی تکرار | حفظ شیرین |
| ۹۰–۱۱۰ | کاردستی/نقاشی | رنگآمیزی «علیاصغر کوچک» | خلاقیت + تثبیت قصه |
| ۱۱۰–۱۲۰ | جمعبندی | بازگویی قصه توسط کودکان + «آفرین» جمعی + تحویل تکلیف خانواده | جمعبندی + پیوند خانه |

## ۳.۰ نمونه جلسه کامل — حلقه ۷ (۱۳ سال) — ۲۴۰ دقیقه

| زمان | بخش | فعالیت | هدف |
|------|-----|--------|-----|
| ۰–۱۵ | معارفه و مرور | مرور تکلیف هفته + گفتگوی «پیام زندگی من» | تثبیت مسیر |
| ۱۵–۵۰ | قرآن (تدبر مستقل) | انتخاب آیه + تدبر فردی + ارائه ۵ دقیقهای | تدبر مستقل |
| ۵۰–۸۵ | نهجالبلاغه جامع | ترجمه و شرح گزیده حکمت + بحث گروهی | فهم عمیق |
| ۸۵–۹۵ | استراحت + میانوعده | گفتگوی آزاد | انس اجتماعی |
| ۹۵–۱۳۰ | کارگاه احکام تکلیف | مسئلهشناسی عملی + پاسخ به پرسشها | احکام کاربردی |
| ۱۳۰–۱۶۵ | آمادگی مربی کوچک | شبیهسازی تدریس برای حلقه ۱ + بازخورد مربی | ایثار و کمک |
| ۱۶۵–۱۹۵ | خطابه | تمرین سخنرانی ۵ دقیقهای + نقد سازنده | مهارت بیان |
| ۱۹۵–۲۲۰ | کارگاه مهارت (آشپزی/مدیریت) | اجرای عملی + برنامهریزی | مهارت زندگی |
| ۲۲۰–۲۴۰ | جمعبندی + دعا | مرور دستاورد + دعای جمعی + تکلیف هفته | جمعبندی معنوی |

## ۵.۰ اصول اجرای موفق سال

| اصل | عمل |
|-----|-----|
| شروع با خانواده | هر ترم با جلسه اولیا آغاز شود |
| جذابیت مداوم | تنوع فعالیتها، مناسبتها و اردوها |
| ثبت پیشرفت | دفتر ارتباطی و کارنامه هر ترم |
| جشن کوچک هر ترم | تقدیر همیشگی، نه فقط پایان سال |
| انعطاف | برنامه متناسب با شرایط (مناسبتها، آبوهوا) |
