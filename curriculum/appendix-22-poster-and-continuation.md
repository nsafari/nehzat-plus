# 🎨 پیوست تکمیلی ۲۲ — پوستر/بروشور معرفی مکتب + برنامه ادامه مسیر (۱۴ سال به بالا)

---

## ۱.۰ پوستر معرفی مکتب (طراحی متن — قابل چاپ)

### ۱.۱ پوستر اصلی (تابلو ورودی)

```
┌─────────────────────────────────────┐
│   بسم الله الرحمن الرحیم            │
│                                     │
│        مَکتَبِ تربیتی               │
│   حضرت قاسم (ع) — پسران             │
│   حضرت سکینه (س) — دختران           │
│   حضرت علیاصغر (ع) و رقیه (س)      │
│         (۴ تا ۱۳ سال)               │
│                                     │
│   قرآن │ اخلاق │ مهارت زندگی │       │
│   الگوسازی از اهل بیت (ع)           │
│                                     │
│   تربیت با محبت، اصلاح با کرامت     │
│   ثبتنام: [تلفن/آدرس]              │
└─────────────────────────────────────┘
```

### ۱.۲ بروشور سهستونی (متن داخلی)

**ستون ۱ — درباره مکتب:**
> «مکتب تربیتی ۱۰ ساله برای کودکان ۴ تا ۱۳ سال؛ بر پایه قرآن، اخلاق اهل بیت (ع) و مهارتهای زندگی. هر حلقه متناسب با سن، برنامه اختصاصی دارد.»

**ستون ۲ — ویژگیها:**
- کلاسهای هفتگی ۲ جلسه (۴–۶ سال: ۲ ساعته / ۷–۱۳ سال: ۴ ساعته)
- مربیان دلسوز + نسبت مناسب (۱:۸ و ۱:۱۰)
- نظامنامه انضباطی مثبت (بدون تنبیه)
- پروژههای عملی: قالیبافی، خیاطی، آشپزی، سخنرانی، مدیریت
- اردوهای مهارتی + جشنهای مناسبتی
- همراهی فعال والدین (دفتر ارتباطی + جلسات ترم)

**ستون ۳ — مسیر ۷ ساله (مختصر):**
| حلقه | محور |
|------|------|
| ۱ | روخوانی قرآن + عقاید ۱ |
| ۲ | صرف و نحو ۱ + خطابه ۱ |
| ۳ | نهجالبلاغه ۱ + مهارت آشپزی |
| ۴ | احکام تکلیف + خیاطی |
| ۵ | تدبر ۱ + مدیریت خانه |
| ۶ | خمس/زکات + مدیریت جلسه |
| ۷ | فارغالتحصیلی + مربی کوچک |

**پایان بروشور:**
> «فرزند شما در مکتب، قرآن میآموزد، اخلاق میسازد و برای زندگی آماده میشود. ثبتنام آغاز شد!»

## ۲.۰ برنامه ادامه مسیر (پس از ۱۳ سال — تکمیلی)

### ۲.۱ چرا ادامه لازم است؟

| دلیل | توضیح |
|------|-------|
| تثبیت هویت | نوجوانی دوره شکلگیری هویت؛ تربیت نباید قطع شود |
| ادامه مهارتها | تکمیل مهارتهای زندگی و اجتماعی |
| مربیگری | فارغالتحصیلان بهترین مربیان آینده مکتباند |
| جامعهسازی | تربیت نسل مبلغ و الگو برای جامعه |

### ۲.۲ ساختار پیشنهادی — حلقه نوجوان (۱۴–۱۶ سال)

| بخش | محتوا |
|-----|-------|
| نام | «حلقه جوانان مکتب» (پسران: قاسم/دختران: سکینه) |
| جلسات | هفتگی ۱ جلسه ۳ ساعته |
| محورها | تدبر پیشرفته، تفسیر موضوعی، اخلاق کاربردی نوجوان، مهارتهای اجتماعی، آمادگی مربیگری |
| فعالیتها | اردوهای جهادی، کمک به حلقههای پایینتر، مسابقات فرهنگی |
| الگو | تثبیت ارتباط با اهل بیت (ع) در فضای نوجوانی |

### ۲.۳ ساختار پیشنهادی — بزرگسال (۱۷ سال به بالا)

| بخش | محتوا |
|-----|-------|
| نام | «حلقه تربیت مربی» |
| هدف | تربیت مربی رسمی مکتب (آموزش روش تدریس، روانشناسی کودک، مدیریت کلاس) |
| محتوا | قرآن و تفسیر، اخلاق حرفهای، روانشناسی تربیتی، کارورزی در حلقهها |
| خروجی | گواهینامه مربیگری + جذب به عنوان مربی مکتب |

### ۲.۴ مسیر کامل یک متربی (خلاصه)

```
۴ سال → ۶ سال        نوآموز (علیاصغر/رقیه)
۷ سال → ۱۳ سال       حلقههای ۱–۷ (قاسم/سکینه)
۱۴ سال → ۱۶ سال      حلقه جوانان (مربی کوچک)
۱۷ سال به بالا        حلقه تربیت مربی (مربی رسمی)
```

## ۳.۰ طرح پیشنهادی جشن فارغالتحصیلی کامل

| بخش | برنامه |
|-----|--------|
| تلاوت | قرائت قرآن توسط فارغالتحصیل |
| سخنرانی | «من و مکتب من» (۷ دقیقه) توسط هر فارغالتحصیل |
| تقدیر | لوح تقدیر + هدیه (قرآن/کتاب اهل بیت) |
| مراسم | اجرای نمایش/سرود توسط حلقههای پایینتر |
| دعا | دعای جمعی برای آینده فارغالتحصیلان |
| خانواده | حضور والدین + جلسه مشاوره مسیر آینده |
