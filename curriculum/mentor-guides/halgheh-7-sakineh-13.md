# 📗 راهنمای مربی: حلقه هفتم مکتب حضرت سکینه (س) — دختران ۱۳ سال (حلقه پایانی)

## ۱.۰ شناسنامه حلقه ۷ (سکینه)

| مورد | مقدار |
|------|-------|
| مکتب | حضرت سکینه بنت الحسین (علیها السلام) |
| جنسیت | دختران |
| سن | ۱۳ سال تمام |
| مدت | ۱ سال تحصیلی = ۲ ترم (هر ترم ۱۶ هفته) |
| جلسات هفتگی | ۲ جلسه × ۴ ساعت |
| کتابهای پایه | قرآن کریم، نهج البلاغه، صحیفه سجادیه، آموزش عقاید ۷، زندگی به سبک دینی ۷، کارگاه احکام، فارسی، صرف و نحو ۶، کتاب خطابه، کتاب مدیریت، زبان انگلیسی |
| نسبت مربی:متربی | ۱:۱۰ |
| اسوه رفتاری | حضرت سکینه (س) — صبر، حیا، ادب، وفاداری، عبادت، شکیبایی در مصیبت، مدیریت |
| پیشنیاز | ارتقا از حلقه ششم |
| خروجی | **فارغالتحصیل مکتب** + آمادگی برای ایفای نقش مربی کوچک |

## ۱.۱ اهداف حلقه (عیناً از سند)

### آموزشی
- قرآن: روانخوانی (تثبیت کامل)، ترجمه (تثبیت)، تدبر (سطح ۶ — کامل و مستقل)، حفظ (تثبیت)
- نهج البلاغه: ترجمه و فهم گزیده جامع (جمعبندی خطبهها، نامهها، حکمتها در ۷ سال)
- صحیفه: ترجمه گزیده (تکمیل) + حفظ گزیده (تثبیت)
- عقاید: جمعبندی اصول دین (استدلال کامل — توانایی دفاع ساده از اعتقادات)
- کارگاه احکام: تکمیل احکام تکلیف (روزه، نماز، طهارت، خمس، زکات، احکام بانوان)
- سبک زندگی: جمعبندی سبک زندگی دینی
- فارسی: روانخوانی، فهم متن، خطابه (جمعبندی)، انشا (کامل)
- عربی: صرف و نحو ۶ (تکمیل)
- انگلیسی: تکمیل (مکالمه و فهم متن ساده)
- مهارتها: آمادگی مربی کوچک + جمعبندی مهارتهای ۷ ساله

### تربیتی
- حیا و عفاف (تثبیت نهایی)
- عبادت عملی (تثبیت کامل)
- صبر و شکیبایی (تثبیت نهایی — الگوی حضرت سکینه)
- محبت و وفاداری به اهل بیت (ع)
- امانتداری (تثبیت نهایی)
- عدالتخواهی (تثبیت نهایی)
- مباحثه و گفتگوی سالم (تثبیت نهایی)
- مسئولیتپذیری در خانه (تثبیت نهایی — مدیریت کامل)
- مدیریت زمان (تثبیت نهایی)
- قدردانی از زحمات دیگران (تثبیت نهایی)
- انس با مسجد و هیئت (تثبیت نهایی)
- عزت نفس (تثبیت نهایی)
- دغدغه اجتماعی (تثبیت نهایی)
- آمادگی مربی کوچک (آغاز — انتقال آموختهها به دیگران)

## ۱.۲ جدول طرح درس — ترم اول (۱۶ هفته)

| هفته | جلسه ۱ (محتوایی) | جلسه ۲ (مهارتی/عملی) | هدف تربیتی |
|------|------------------|----------------------|------------|
| ۱ | معارفه + مرور ۶ سال + معرفی «آمادگی مربی کوچک» | تعیین مسئولیتها | مسئولیتپذیری |
| ۲ | قرآن: تدبر مستقل (سطح ۶) | آمادگی مربی: مشاهده حلقه ۱ | ایثار و کمک |
| ۳ | نهج البلاغه: گزیده جامع | کارگاه احکام: تکمیل | عبادت عملی |
| ۴ | عقاید: جمعبندی اصول | صرف و نحو ۶ | اعتماد به نفس |
| ۵ | قرآن: ترجمه و تدبر مستقل | آمادگی مربی: همیار حلقه ۱ | ایثار و انتقال |
| ۶ | فارسی: انشا جمعبندی | انگلیسی: مکالمه | عزت نفس |
| ۷ | صحیفه: ترجمه مکارم الاخلاق | شبیهسازی: شرایط سخت | صبر |
| ۸ | **ارزشیابی تکوینی** | اردوی جمعبندی + زیارت | جمعبندی معنوی |
| ۹ | نهج البلاغه: گزیده جامع | احکام بانوان (تکمیل) | حیا و عفاف |
| ۱۰ | قرآن: تدبر مستقل | همیار مربی حلقه ۲ | انتقال آموختهها |
| ۱۱ | خطابه: جمعبندی ۷ سال | مدیریت جلسه کامل | مدیریت |
| ۱۲ | عقاید: جمعبندی امامت/معاد | صرف و نحو: مرور | مباحثه سالم |
| ۱۳ | سبک زندگی: تصمیمگیری دینی | آشپزی: سفره جمعبندی | مسئولیتپذیری |
| ۱۴ | صحیفه: حفظ گزیده | خیاطی/قالیبافی: پروژه نهایی | قدردانی |
| ۱۵ | نهج البلاغه: پیام ۷ ساله | ارائه: فارغالتحصیلی | عزت نفس |
| ۱۶ | **ارزشیابی پایانی** | جشن فارغالتحصیلی | جمعبندی |

| ۳ | نهج البلاغه: تکمیل | ۱۱ | خطابه نهایی فارغالتحصیلی |
| ۴ | عقاید: دفاع | ۱۲ | حیا و عفاف (نهایی) |
| ۵ | انشا نهایی | ۱۳ | شبیهسازی مدیریت شرایط |
| ۶ | صحیفه: جمعبندی | ۱۴ | جلسه فارغالتحصیلی |
| ۷ | صرف و نحو | ۱۵ | مرور ۷ ساله |
| ۸ | **ارزشیابی + اردو** | ۱۶ | **جشن فارغالتحصیلی نهایی** |
