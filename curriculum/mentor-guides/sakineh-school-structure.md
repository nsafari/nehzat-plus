# 📗 راهنمای مربی: مکتب حضرت سکینه (س) — دختران

## ۰. شناسنامه کلی مکتب سکینه (س)

| مورد | مقدار |
|------|-------|
| مکتب | حضرت سکینه بنت الحسین (علیها السلام) |
| جنسیت | دختران |
| محدوده سنی | ۷ تا ۱۳ سال (۷ حلقه سالانه) |
| ساختار | ۷ حلقه × ۲ ترم (هر ترم ۱۶ هفته) |
| جلسات هفتگی | ۲ جلسه × ۴ ساعت |
| نسبت مربی:متربی | ۱:۱۰ |
| اسوه رفتاری | حضرت سکینه (س) — صبر، حیا، ادب، وفاداری، شکیبایی در مصیبت، عبادت و اتصال به خدا |

### تفاوتهای کلیدی مکتب دختران (نسبت به پسران)

| محور | مکتب قاسم (پسران) | مکتب سکینه (دختران) |
|------|-------------------|----------------------|
| اسوه | قاسم بن الحسن — شجاعت، ایثار | سکینه بنت الحسین — صبر، حیا، ادب |
| مهارتهای فنی | جوشکاری، برق، لولهکشی، نجاری | خیاطی، آشپزی، هنرهای خانگی، قالیبافی، خوشنویسی، مدیریت خانه |
| زبان خارجی | لاتین | لاتین (با محتوای متناسب) |
| تأکید تربیتی | آمادگی دفاعی، سیاست | حیا و عفاف، مدیریت خانه، تربیت فرزند (در سنین بالاتر)، صبر |
| مهارتهای مدیریتی | مدیریت جلسات | مدیریت خانه و جمعهای خانوادگی + مدیریت جلسات |
| ورزش | متناسب پسران | متناسب دختران (با رعایت موازین) |
