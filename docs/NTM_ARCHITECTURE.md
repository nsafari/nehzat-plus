# Nehzat Teacher-Mentor Certification System (NTM)
## معماری نظام آموزشی تربیت مربی

**تاریخ**: ۱۴۰۵/۰۵/۰۷ | **وضعیت**: طرح پایه | **نسخه**: v0.1

---

## ۱. خلاصه اجرایی

یک نظام آموزشی ماژولار، گام‌به‌گام و فرآیندی برای تربیت مربی از سطح کاملاً مبتدی تا مربی‌ساز.
مبتنی بر مبانی اسلامی (قرآن، حدیث، اندیشمندان) و استانداردهای جهانی تربیت مربی.
طراحی شده برای مخاطبان ۵ تا ۵۰ سال با ۵ رده سنی مجزا.

## ۸. مسیر ورود محتوا (Content Input Pipeline)

### قالب استاندارد ماژول
هر ماژول شامل این بخش‌هاست:
- **Metadata**: کد، عنوان، نویسنده، سطح، رده سنی، پیش‌نیاز، زمان، روش
- **اهداف یادگیری**: ۳-۵ هدف قابل سنجش (Bloom's + اسلامی)
- **محتوای اصلی**: بخش‌بندی شده با آیات، احادیث، مفاهیم کلیدی
- **فعالیت‌ها**: تمرین‌های فردی و گروهی با زمان و دستورالعمل
- **ارزشیابی**: سؤالات و Rubric
- **تطبیق سنی**: تغییرات پیشنهادی برای هر رده سنی
- **منابع**: آیات، احادیث، منابع فارسی و انگلیسی

### فرآیند ۵ مرحله‌ای
1. **تألیف** (نویسنده) ← ۲. **بازبینی علمی** (داور) ← ۳. **ویرایش فنی** (ویراستار) ← ۴. **تأیید نهایی** (شورای علمی) ← ۵. **انتشار** (مدیر سیستم)

### خروجی‌ها
PDF (چاپ), HTML (وب), SCORM (LMS), JSON (داده), Markdown (نسخه سبک)

## ۹. مبانی نظری پژوهش‌شده

- **قرآن کریم**: ۱۴ آیه کلیدی با موضوع تربیت (لقمان، آل‌عمران، نحل، اسراء، کهف و...)
- **حدیث**: ۲۹ روایت از معصومین از منابع Al-Kafi, Nahj al-Balaghah, Ghurar al-Hikam, Bihar al-Anwar, Wasa'il al-Shi'a
- **اندیشمندان اسلامی**:
  - امام خمینی: ۵ مؤلفه (تزکیه قبل تعلیم، مربی ربانی، وحدت قول و عمل، تربیت جامع، تدریج و مدارا)
  - آیت‌الله خامنه‌ای: ۲۰ بیانیه کلیدی درباره نقش معلم
  - آقا مجتبی تهرانی: ۳ بعدی بودن تربیت (بصری، سمعی، رفتاری)، ۴ محیط تربیتی
  - علی صفایی حائری (Ein.Sad): ۵ مرحله رشد متربی، مسؤولیت و سازندگی
  - آیت‌الله محی‌الدین حائری شیرازی: فطرت/طبیعت دوگانه، ۳ مرحله تربیت
- **جهانی**: ICF, ATD, IBSTPI, Bloom's, Andragogy, ADDIE, UbD, PBL
- **شرقی**: Confucius (۱۰ اصل), Guru-Shishya, Lesson Study, Maktabkhaneh
