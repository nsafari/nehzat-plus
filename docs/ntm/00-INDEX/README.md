## ۴ مسیر یادگیری

- **مسیر A** (کودک/نوجوان): ۵-۹ → ۱۰-۱۴ → ۱۵-۲۱ (NTM-1 و NTM-2)
- **مسیر B** (معلمان شاغل): NTM-1 فشرده ۳ ماهه → NTM-2 در ۶ ماه → NTM-3 در ۱ سال
- **مسیر C** (والدین): بسته منتخب C1-4 + E1-6 + D1-4 + B1-5
- **مسیر D** (فعالان فرهنگی): NTM-2 + NTM-3 کامل + تخصص مدیریت
