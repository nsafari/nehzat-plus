# فرآیند ۵ مرحله‌ای تولید محتوا — NTM

## خط لوله تولید

```
تألیف → بازبینی علمی → ویرایش فنی → تأیید نهایی → انتشار
```

---

## مرحله ۱: تألیف (Authoring)

**نقش:** نویسنده محتوا (مربی‌ساز / متخصص موضوع)

**وظایف:**
- نگارش محتوای ماژول بر اساس قالب استاندارد
- رعایت اصول نگارش علمی-روان (ساده، دقیق، مستند)
- استناد به منابع معتبر (قرآن، حدیث، نظریه‌ها)
- طراحی فعالیت‌ها و سؤالات ارزشیابی
- تحویل: فایل Markdown با وضعیت `پیش‌نویس`

**چک‌لیست تألیف:**
- [ ] اهداف یادگیری با افعال قابل سنجش نوشته شده‌اند
- [ ] محتوای اصلی با آیات و روایات مستند شده است
- [ ] فعالیت‌ها دارای زمان و دستورالعمل کامل هستند
- [ ] سؤالات ارزشیابی با اهداف هماهنگ هستند
- [ ] تطبیق سنی برای همه رده‌ها انجام شده است
- [ ] منابع به صورت کامل ذکر شده‌اند

---

## مرحله ۲: بازبینی علمی (Scientific Review)

**نقش:** داور علمی (متخصص همان حوزه)

**وظایف:**
- بررسی صحت علمی محتوا
- تأیید مستندات و استنادات
- بررسی تطابق با مبانی اسلامی
- ارائه بازخورد اصلاحی
- تحویل: گزارش بازبینی + فایل با وضعیت `بازبینی‌شده` یا ارجاع برای اصلاح

**معیارهای بازبینی:**
- [ ] صحت مفاهیم و تعاریف
- [ ] صحت استناد به آیات و روایات
- [ ] انسجام منطقی مطالب
- [ ] تطابق با آخرین یافته‌های علمی
- [ ] عدم تضاد با مبانی دینی

---

## مرحله ۳: ویرایش فنی (Technical Editing)

**نقش:** ویراستار زبانی و فنی

**وظایف:**
- ویرایش زبانی (نحو، نگارش، املاء)
- یکسان‌سازی اصطلاحات
- رعایت قالب استاندارد
- بهینه‌سازی برای خروجی‌های مختلف (PDF, HTML, SCORM)
- تحویل: فایل ویرایش‌شده

**چک‌لیست ویرایش:**
- [ ] نگارش روان و یکدست است
- [ ] اصطلاحات تخصصی یکسان‌سازی شده‌اند
- [ ] قالب بندی مطابق استاندارد است
- [ ] غلط‌های املایی و نگارشی اصلاح شده است
- [ ] نشانه‌گذاری فارسی رعایت شده است

---

## مرحله ۴: تأیید نهایی (Final Approval)

**نقض:** شورای علمی NTM

**وظایف:**
- بررسی نهایی کیفیت
- تطابق با اهداف کلان نظام آموزشی
- تصویب برای انتشار
- تحویل: فایل با وضعیت `نهایی`

---

## مرحله ۵: انتشار (Publishing)

**نقش:** مدیر سیستم / مسئول فناوری

**وظایف:**
- تبدیل به فرمت‌های خروجی (PDF, HTML, SCORM, JSON, MD)
- بارگذاری در سیستم مدیریت محتوا
- ثبت در کتابخانه ماژول‌ها
- اعلام به ذی‌نفعان

---

## فرمت‌های خروجی

| فرمت | کاربرد | توضیحات |
|:----:|--------|---------|
| PDF | چاپ | نسخه قابل چاپ با صفحه‌آرایی مناسب |
| HTML | وب | نسخه قابل نمایش در مرورگر |
| SCORM | LMS | استاندارد قابل استفاده در سامانه‌های آموزش مجازی |
| JSON | داده | نسخه ساختاریافته برای تبادل داده |
| Markdown | سبک | نسخه مبدأ برای ویرایش و نگهداری |
