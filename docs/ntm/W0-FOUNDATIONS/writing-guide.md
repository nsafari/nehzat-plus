# راهنمای نگارش محتوای آموزشی — NTM

## اصول کلی

### ۱. مخاطب‌شناسی
- برای هر ماژول، رده سنی هدف را دقیق مشخص کنید
- از مثال‌های متناسب با تجربه زیسته آن رده استفاده کنید
- سطح دشواری را با پیش‌نیازها هماهنگ کنید

### ۲. زبان و لحن
- فارسی روان و معیار (از فارسی‌سازی‌های غلو شده پرهیز کنید)
- لحن علمی اما صمیمی، نه خشک و رسمی
- جملات کوتاه و مفهوم (حداکثر ۲۵-۳۰ کلمه)
- پرهیز از ابهام و کلی‌گویی

### ۳. ساختاردهی
- هر مبحث را با یک سؤال یا چالش شروع کنید
- مطالب را به بخش‌های کوچک و قابل هضم تقسیم کنید
- از مثال‌های عینی و ملموس استفاده کنید
- هر بخش را با یک خلاصه کوتاه جمع‌بندی کنید

### ۴. مستندسازی
- هر ادعای علمی را با منبع مستند کنید
- آیات را با ذکر سوره و آیه بیاورید
- احادیث را با منبع اصلی ذکر کنید
- از منابع معتبر و به‌روز استفاده کنید

### ۵. فعالیت‌محوری
- هر مبحث نظری باید با یک فعالیت عملی همراه باشد
- فعالیت‌ها باید زمان‌بندی مشخص داشته باشند
- فعالیت‌ها باید قابل اجرا در کلاس باشند

## ساختار جملات اهداف یادگیری

```
پس از پایان این ماژول، شرکت‌کننده می‌تواند:

۱. [فعل] + [محتوا] + [بافت]
۲. [فعل] + [محتوا] + [بافت]
...
```

**افعال مجاز:** تعریف کند، توضیح دهد، تحلیل کند، مقایسه کند، اجرا کند، طراحی کند، ارزیابی کند، تمایز قائل شود، استدلال کند، نقد کند

**افعال غیرمجاز:** بداند، بفهمد، یاد بگیرد، آشنا شود، درک کند (اینها قابل سنجش نیستند)

---

## مثال: یک ماژول خوب

**کد:** A3 | **عنوان:** اهداف تربیت از دیدگاه قرآن  
**سطح:** NTM-1 | **زمان:** ۹۰ دقیقه

**اهداف:**
1. سه هدف اصلی تربیت از دیدگاه قرآن را نام ببرد
2. تفاوت میان هدف غایی و اهداف واسطی را توضیح دهد
3. یک هدف تربیتی را از یک آیه استخراج و تحلیل کند

**فعالیت کلیدی:** شرکت‌کنندگان در گروه‌های ۳ نفره یک آیه انتخابی را تحلیل می‌کنند و هدف تربیتی مستخرج از آن را روی پوستر ارائه می‌دهند.

## املاء و نگارش

- استفاده از «می‌» و «نمی‌» به صورت جدا: «می‌تواند»، «نمی‌شود»
- استفاده از «است» به صورت جدا: «مهم است»
- نشانه جمع «ها» به صورت جدا: «کتاب‌ها»
- استفاده از کسر اضافه (ـِـ) در جای مناسب: «هدفِ تربیت»
- رعایت نیم‌فاصله برای کلمات مرکب
