# نظام سطوح NTM — معیارها و شایستگی‌ها

## ساختار سطوح سه‌گانه

NTM دارای سه سطح تصاعدی است:

### سطح ۱: مربی‌یار (Assistant Coach)
**کد:** NTM-L1

| معیار | الزامات |
|-------|---------|
| ماژول‌های پیش‌نیاز | A1-A5, B1-B4, C1-C3, E1-E3 |
| ساعت آموزش | ۱۲۰ ساعت (۴۰ نظری + ۸۰ عملی) |
| آزمون کتبی | نمره ≥ ۷۰ از ۱۰۰ |
| آزمون عملی | ۲ جلسه تدریس مشاهده‌شده با نمره ≥ ۶۰ |
| پورتفولیو | ۵ مستند (طرح درس، گزارش بازتابی) |
| مدت اعتبار | ۳ سال |

**شایستگی‌های خروجی:**
- توانایی اجرای طرح درس از پیش تعیین‌شده
- آشنایی با مبانی تربیت اسلامی
- مهارت ارتباط مؤثر با متربیان
- توانایی مدیریت کلاس تحت نظارت

### سطح ۲: مربی (Coach)
**کد:** NTM-L2

| معیار | الزامات |
|-------|---------|
| ماژول‌های پیش‌نیاز | A6-A10, B5-B9, C4-C7, D1-D6, E4-E7, F1-F5 |
| ساعت آموزش | ۲۵۰ ساعت (۱۰۰ نظری + ۱۵۰ عملی) |
| پیش‌نیاز | دارا بودن سطح ۱ و ۲ سال سابقه عملی |
| آزمون کتبی | نمره ≥ ۷۵ از ۱۰۰ |
| آزمون عملی | ۵ جلسه تدریس با نمره ≥ ۷۰ (حداقل ۲ جلسه ارزیابی ناشناس) |
| مصاحبه تخصصی | قبولی در کمیته علمی |
| پورتفولیو | ۱۵ مستند شامل فیلم تدریس |
| مدت اعتبار | ۵ سال |

**شایستگی‌های خروجی:**
- توانایی طراحی و اجرای مستقل دوره آموزشی
- تحلیل نیازهای آموزشی متربیان
- ارزشیابی و بازخورد اثربخش
- رهبری کلاس و مدیریت گروه

### سطح ۳: مربی‌ساز (Master Coach / Trainer of Trainers)
**کد:** NTM-L3

| معیار | الزامات |
|-------|---------|
| ماژول‌های پیش‌نیاز | تمام محورهای A-I |
| ساعت آموزش | ۴۵۰ ساعت (۱۵۰ نظری + ۳۰۰ عملی) |
| پیش‌نیاز | دارا بودن سطح ۲ و ۳ سال سابقه مربیگری |
| آزمون کتبی | نمره ≥ ۸۰ از ۱۰۰ |
| آزمون عملی | ۱۰ جلسه با نمره ≥ ۸۰ |
| پروژه پایانی | طراحی یک دوره کامل آموزشی (حداقل ۲۰ ساعت) + دفاع |
| پورتفولیو | ۳۰ مستند |
| تدریس مشاهده‌شده | ارزیابی توسط ۲ مربی‌ساز دیگر |
| مدت اعتبار | ۷ سال |

**شایستگی‌های خروجی:**
- توانایی تربیت و ارزیابی مربیان سطح ۱ و ۲
- طراحی برنامه درسی و نظام ارزشیابی
- نظارت و منتورینگ مربیان
- رهبری آموزشی در سطح سازمانی
