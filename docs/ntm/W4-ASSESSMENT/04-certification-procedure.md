# نظام گواهی‌دهی NTM — رویه‌ها و استانداردها

## مراحل صدور گواهی

```
                  ┌──────────────────┐
                  │  تکمیل ماژول‌ها   │
                  │  + ساعت آموزشی   │
                  └────────┬─────────┘
                           ▼
                  ┌──────────────────┐
                  │  ثبت‌نام در آزمون │
                  │  (سامانه NTM)    │
                  └────────┬─────────┘
                           ▼
                  ┌──────────────────┐
                  │  آزمون کتبی      │
                  │  (حدنصاب نمره)   │
                  └────────┬─────────┘
                           ▼
                  ┌──────────────────┐
                  │  آزمون عملی      │
                  │  (تدریس مشاهده‌شده)│
                  └────────┬─────────┘
                           ▼
                  ┌──────────────────┐
                  │  بررسی پورتفولیو │
                  │  (کمیته علمی)    │
                  └────────┬─────────┘
                           ▼
                  ┌──────────────────┐
                  │  صدور گواهی      │
                  │  + ثبت در سامانه │
                  └──────────────────┘
```

## کمیته ارزشیابی

**ترکیب (برای هر سطح):**

| سطح | اعضای کمیته |
|------|------------|
| L1 | ۱ مربی‌ساز + ۱ مربی سطح ۲ + ۱ نماینده مدیریت آموزشی |
| L2 | ۲ مربی‌ساز + ۱ استاد دانشگاه یا حوزه |
| L3 | ۳ مربی‌ساز ارشد + ۱ نماینده شورای علمی NTM + ۱ مهمان علمی |

**وظایف کمیته:**
- بررسی پورتفولیو
- برگزاری مصاحبه تخصصی
- تعیین صلاحیت نهایی
- رسیدگی به اعتراضات

### المان‌های امنیتی
- QR Code دو بعدی برای استعلام آنلاین
- کد رهگیری یکتا (UUID)
- هولوگرام NTM
- مهر خشک کمیته علمی
- امضای دیجیتال (در نسخه الکترونیک)

## ثبت در سامانه

پس از صدور گواهی، اطلاعات زیر در سامانه NTM ثبت می‌شود:
- نام و نام خانوادگی کامل
- کد ملی
- سطح گواهی
- تاریخ صدور و انقضا
- کد رهگیری
- امتیاز نهایی (در صورت تمایل فرد)
- سابقه تدریس ثبت‌شده

## تمدید گواهی

| سطح | مدت اعتبار | شرایط تمدید |
|------|------------|-------------|
| L1 | ۳ سال | ۴۰ ساعت بازآموزی + ۱ تدریس موفق |
| L2 | ۵ سال | ۸۰ ساعت بازآموزی + ۳ تدریس موفق + ۱ مقاله یا کارگاه |
| L3 | ۷ سال | ۱۲۰ ساعت بازآموزی + تربیت حداقل ۳ مربی L1 |

## تعلیق و لغو گواهی

**تعلیق موقت (۳ تا ۶ ماه):**
- تخلف اخلاقی در محیط آموزشی
- عدم حضور در دوره‌های بازآموزی
- شکایت مستند از سوی متربیان

**لغو دائم:**
- تخلف مالی اثبات‌شده
- سوءاستفاده جنسی یا اخلاقی
- جعل گواهی یا مدارک
- محکومیت قضایی مرتبط

## اعتراض و تجدیدنظر

متربی می‌تواند ظرف ۱۵ روز پس از اعلام نتایج، اعتراض خود را به کمیته تجدیدنظر ارائه دهد:
۱. ثبت اعتراض در سامانه (فرم اعتراض)
۲. بررسی اولیه توسط دبیرخانه NTM (۳ روز)
۳. بررسی تخصصی توسط کمیته تجدیدنظر (۱۵ روز)
۴. اعلام نتیجه نهایی (قطعی)
