# تضمین کیفیت در NTM

## چرخه تضمین کیفیت

```
     ┌─────────────┐
     │  برنامه‌ریزی │
     │  (Plan)      │
     └──────┬──────┘
            ▼
     ┌─────────────┐
     │  اجرا       │◄──── بازخورد
     │  (Do)       │       بیرونی
     └──────┬──────┘
            ▼
     ┌─────────────┐
     │  ارزیابی    │◄──── بازخورد
     │  (Check)    │       درونی
     └──────┬──────┘
            ▼
     ┌─────────────┐
     │  اصلاح      │
     │  (Act)      │
     └─────────────┘
```

## شاخص‌های کلیدی کیفیت (KQI)

| شاخص | نحوه سنجش | حد مطلوب |
|------|----------|----------|
| **رضایت متربی** | پرسشنامه پایان دوره | ≥ ۸۰٪ رضایت |
| **تحقق اهداف** | آزمون قبل و بعد | ≥ ۷۰٪ پیشرفت |
| **ماندگاری یادگیری** | آزمون ۳ ماه پس از دوره | ≥ ۶۰٪ حفظ محتوا |
| **کاربرد عملی** | گزارش خوداظهاری ۶ ماه بعد | ≥ ۵۰٪ کاربرد |
| **کیفیت تدریس** | ارزیابی ناشناس | ≥ ۷۵٪ کیفیت خوب |
| **بازماندگی** | درصد تکمیل دوره | ≥ ۸۰٪ |

## ممیزی داخلی

### ممیزی دوره‌ها
- هر دوره حداقل یک بار در طول اجرا توسط ناظر کیفیت بازدید می‌شود
- گزارش بازدید ظرف ۴۸ ساعت به تیم اجرایی ابلاغ می‌گردد
- نتایج ممیزی در سامانه ثبت می‌شود

### ممیزی مربیان
- هر مربی حداقل سالی یک بار ارزیابی ناشناس می‌شود
- مربیان جدید (زیر ۲ سال) هر ترم یک بار ارزیابی می‌شوند
- نتایج ارزیابی محرمانه است و فقط با خود مربی در میان گذاشته می‌شود

## بازخورد ذی‌نفعان

### متربیان
- پرسشنامه پایان هر ماژول
- گروه بحث تلگرامی/واتساپی
- جلسات نقد در پایان هر سطح
- فرم پیشنهادات در سامانه

### مربیان
- جلسات هم‌اندیشی ماهانه
- نظرخواهی از مربیان درباره محتوا
- ارزیابی صعودی (بالا به پایین)

### کارفرمایان (مراکز آموزشی)
- نظرخواهی از مدیران مراکز
- پیگیری عملکرد فارغ‌التحصیلان
- جلسات سالانه با شرکا

## بهبود مستمر

| بازه | اقدام |
|------|-------|
| **پس از هر ماژول** | تحلیل نتایج ارزشیابی، اصلاح جزئی |
| **پس از هر سطح** | بازبینی کلی محتوا و روش |
| **سالانه** | بازنگری اساسی برنامه NTM |
| **سه ساله** | ارزیابی خارجی و اعتبارسنجی مجدد |

## استانداردهای مرجع

NTM برای تضمین کیفیت خود به استانداردهای زیر توجه دارد:
- ISO 21001:2018 (مدیریت سازمان‌های آموزشی)
- ISO 29993:2017 (خدمات یادگیری غیررسمی)
- IAT (International Association of Trainers) Standards
- استانداردهای شورای عالی انقلاب فرهنگی ایران
