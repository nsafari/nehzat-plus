# فرآیند اجرای یک دوره NTM

## چرخه کامل اجرا

```
─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    پیش از دوره (۴ هفته قبل)
─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
          │
          ▼
    ۱. تحلیل نیاز
    ۲. تعیین سطح متربیان
    ۳. تدوین طرح دوره
    ۴. آماده‌سازی مواد آموزشی
    ۵. ثبت‌نام و سازماندهی
          │
─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    حین دوره
─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
          │
          ▼
    ۶. اجرای جلسات
    ۷. ارزشیابی تکوینی
    ۸. بازخورد مستمر
    ۹.Adjustment بر اساس نتایج
          │
─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
    پس از دوره (۲ هفته پس از)
─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
          │
          ▼
    ۱۰. ارزشیابی پایانی
    ۱۱. تحلیل نتایج
    ۱۲. صدور گواهی
    ۱۳. گزارش پایانی
    ۱۴. آرشیو مستندات
```

## گام‌های تفصیلی

### گام ۱: تحلیل نیاز (۴ هفته قبل)

| فعالیت | ابزار | مسئول |
|--------|-------|-------|
| بررسی پیشینه متربیان | پرسشنامه | مربی |
| تعیین اهداف دوره | ماتریس نیاز-هدف | مربی + هماهنگ‌کننده |
| شناخت محدودیت‌ها (زمان، فضا، بودجه) | چک‌لیست | هماهنگ‌کننده |

### گام ۲: تعیین سطح متربیان

| روش | توضیح |
|------|-------|
| پیش‌آزمون کتبی (۲۰ سؤال) | سنجش دانش پایه |
| مصاحبه کوتاه (۱۰ دقیقه) | شناخت نگرش و انگیزه |
| خوداظهاری | سطح تجربه قبلی |
| تعیین سطح نهایی | انتخاب مسیر A/B/C |

### گام ۳: تدوین طرح دوره

| بخش | محتوا |
|------|-------|
| عنوان دوره | مطابق با محور/ماژول NTM |
| اهداف کلی | ۳-۵ هدف اصلی |
| اهداف جزئی | ۱۰-۱۵ هدف رفتاری (SMART) |
| جلسات | جدول ۱۲-۱۶ جلسه‌ای |
| روش‌ها | ترکیب سخنرانی، بحث، تمرین، پروژه |
| ارزشیابی | تکوینی + پایانی |
| منابع | کتاب، جزوه، چندرسانه‌ای |

### گام ۴: آماده‌سازی مواد آموزشی

- اسلایدهای جلسات (حداکثر ۱۵ اسلاید در هر جلسه ۹۰ دقیقه)
- کاربرگ‌های تمرین
- سناریوهای موردی
- فیلم‌ها و کلیپ‌های مرتبط
- کتابچه راهنمای متربی

### گام ۵: ثبت‌نام و سازماندهی

- تأیید نهایی لیست متربیان
- گروه‌بندی (تیم‌های ۳-۵ نفره)
- اعلام برنامه زمانی
- ایجاد گروه ارتباطی (تلگرام/واتساپ)

### گام ۶-۹: اجرا و ارزشیابی تکوینی

رجوع شود به:
- [راهنمای تسهیل‌گری](01-facilitation-guide.md)
- [ابزارهای ارزشیابی](../W4-ASSESSMENT/03-rubrics-and-tools.md)

### گام ۱۰-۱۴: اختتامیه

| فعالیت | توضیح | زمان |
|--------|-------|------|
| آزمون پایانی | ۴۰ سؤال (کتبی + عملی) | آخرین جلسه |
| بازخورد فردی | جلسه ۱۵ دقیقه‌ای با هر متربی | ظرف ۱ هفته |
| پرسشنامه رضایت | استاندارد NTM | جلسه پایانی |
| گزارش پایانی | تحلیل نتایج + پیشنهادات | ظرف ۲ هفته |
| صدور گواهی | پس از تأیید نتایج | ظرف ۳ هفته |
| آرشیو | بارگذاری همه مستندات در سامانه | ظرف ۳ هفته |
