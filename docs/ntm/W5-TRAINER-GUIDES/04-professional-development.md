# توسعه حرفه‌ای مربیان NTM

## مسیر رشد حرفه‌ای

```
مربی‌یار (L1) ────► مربی (L2) ────► مربی‌ساز (L3)
    │                    │                    │
    ▼                    ▼                    ▼
  دانش پایه          تخصص‌یابی         رهبری آموزشی
  اجرای طرح درس      طراحی دوره        تربیت مربی
  نظارت مستقیم       استقلال کامل       نوآوری و پژوهش
```

## مؤلفه‌های توسعه حرفه‌ای

### ۱. یادگیری مداوم (Continuous Learning)

| روش | توضیح | ساعت سالانه |
|-----|-------|------------|
| مطالعه فردی | کتاب، مقاله، منابع آنلاین | ۵۰ ساعت |
| شرکت در دوره‌ها | دوره‌های تخصصی آموزشی | ۳۰ ساعت |
| همایش‌ها و کارگاه‌ها | داخلی و بین‌المللی | ۲۰ ساعت |
| **جمع** | | **۱۰۰ ساعت** |

### ۲. یادگیری گروهی (Collaborative Learning)

| فعالیت | توضیح | تکرار |
|--------|-------|-------|
| جلسات هم‌اندیشی | تبادل تجربیات، رفع چالش‌ها | ماهانه |
| Lesson Study | طراحی جمعی یک درس، مشاهده و تحلیل | هر ترم |
| گروه کتابخوانی | مطالعه و بحث درباره یک کتاب آموزشی | هر ۲ ماه |
| Peer Coaching | مشاهده متقابل و بازخورد | هر ماه |

### ۳. تأمل در عمل (Reflective Practice)

مربی NTM موظف است پس از هر جلسه آموزشی یک **گزارش بازتابی** کوتاه (۵-۱۰ خط) بنویسد:

```markdown
### فرم گزارش بازتابی جلسه

تاریخ: _____ عنوان جلسه: _____

**۱. چه اتفاقی افتاد؟**
[توصیف عینی رویدادهای کلیدی]

**۲. چه احساسی دارم؟**
[واکنش عاطفی به جلسه]

**۳. چه آموختم؟**
[تحلیل و استخراج درس‌ها]

**۴. چه تغییری ایجاد می‌کنم؟**
[اقدامات اصلاحی برای جلسه بعد]
```

### ۴. بازخورد ۳۶۰ درجه

| منبع بازخورد | تکرار | ابزار |
|-------------|-------|-------|
| خودارزیابی | هر جلسه | فرم بازتابی |
| متربیان | پایان هر ماژول | پرسشنامه |
| همتایان | ماهانه | مشاهده + فرم |
| مربی راهنما | فصلی | نشست توسعه‌ای |
| مدیر آموزشی | سالانه | ارزیابی عملکرد |

## طرح توسعه فردی (IDP)

هر مربی سالانه یک طرح توسعه فردی (Individual Development Plan) تدوین می‌کند:

| بخش | محتوا |
|------|-------|
| **خودارزیابی** | نقاط قوت، زمینه‌های بهبود، علایق |
| **اهداف سالانه** | ۳ هدف SMART (مشخص، قابل سنجش، دست‌یافتنی، مرتبط، زمان‌دار) |
| **فعالیت‌های توسعه** | دوره‌ها، کتاب‌ها، کارگاه‌ها، پروژه‌ها |
| **منابع مورد نیاز** | مالی، زمانی، حمایت سازمانی |
| **جدول زمانی** | برنامه ماهانه اقدامات |
| **شاخص‌های موفقیت** | چگونه می‌فهمم به هدف رسیده‌ام؟ |

## نظام تشویق و ارتقا

| دستاورد | پاداش |
|---------|-------|
| نمره عالی در ارزیابی سالانه | افزایش حقوق ۱۰٪ |
| ارائه مقاله یا کارگاه | کمک هزینه سفر علمی |
| تربیت ۵+ مربی L1 | ارتقا به سطح L3 |
| ۲ سال تدریس ممتاز | تقدیر در جشنواره سالانه NTM |
| نوآوری آموزشی اثبات‌شده | ثبت به نام مربی در سامانه |
