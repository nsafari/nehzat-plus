# یکپارچه‌سازی با LMS (سامانه آموزش مجازی)

## معماری یکپارچه‌سازی

NTM از طریق API REST با سامانه LMS ارتباط برقرار می‌کند:

```
┌─────────────────┐        ┌─────────────────┐
│   سامانه NTM    │◄──────►│   LMS موجود     │
│  (مدیریت محتوا)  │  API   │  (اجرای دوره)   │
└─────────────────┘        └─────────────────┘
         │                         │
         │                         │
         ▼                         ▼
┌─────────────────┐        ┌─────────────────┐
│  بانک اطلاعاتی  │        │  پلتفرم یادگیری │
│   NTM (SQL)     │        │  (Moodle/Tensor) │
└─────────────────┘        └─────────────────┘
```

## استانداردهای پشتیبانی‌شده

| استاندارد | وضعیت | توضیح |
|-----------|--------|-------|
| SCORM 1.2 | ✅ پشتیبانی کامل | محتوای قابل انتقال |
| SCORM 2004 | ✅ پشتیبانی کامل | ردیابی پیشرفت دقیق |
| xAPI (Tin Can) | ✅ توصیه‌شده | ردیابی فعالیت‌های خارج از LMS |
| LTI 1.3 | ✅ پشتیبانی کامل | ورود یکپارچه از LMS |
| cmi5 | 🔄 در دست اجرا | نسل جدید محتوای قابل ردیابی |

## ساختار محتوای دیجیتال

### هر ماژول NTM در LMS شامل:

```
ماژول A1
├── معرفی (ویدیوی ۳-۵ دقیقه‌ای)
├── درس‌نامه (متن + تصاویر)
├── ویدیوی آموزشی (۱۵-۲۰ دقیقه)
├── اسلایدهای جلسه (PDF)
├── آزمونک (۵-۱۰ سؤال)
├── تمرین تعاملی
├── تکلیف ارسالی
├── بحث گروهی
└── منابع تکمیلی
```

### قالب‌بندی محتوا

| نوع محتوا | فرمت | اندازه حداکثر |
|-----------|------|--------------|
| ویدیو | MP4 (H.264) | ۵۰۰ مگابایت |
| صدا | MP3 | ۱۰۰ مگابایت |
| تصویر | JPG/PNG | ۱۰ مگابایت |
| سند | PDF | ۵۰ مگابایت |
| تعاملی | H5P | ۲۰ مگابایت |

## ردیابی پیشرفت (Tracking)

| شاخص | نحوه ردیابی | نمایش به مربی |
|------|------------|--------------|
| تکمیل محتوا | درصد مشاهده/خواندن/گذراندن | داشبورد پیشرفت |
| نمرات آزمون‌ها | خودکار از LMS | جدول نمرات |
| زمان مطالعه | لاگ فعالیت | میانگین زمان هر ماژول |
| مشارکت در بحث | تعداد پست‌ها | گزارش مشارکت |
| تحویل تکالیف | تاریخ تحویل | جدول وضعیت |
