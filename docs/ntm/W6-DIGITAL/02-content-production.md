# خط تولید محتوای دیجیتال NTM

## مراحل تولید

```
┌────────────────┐
│  نگارش محتوا   │  مربیان محتوایی
│  (متن اصلی)    │  (Subject Matter Experts)
└───────┬────────┘
        ▼
┌────────────────┐
│  ویرایش علمی   │  کارشناسان محتوایی NTM
│  و فنی         │
└───────┬────────┘
        ▼
┌────────────────┐
│  تبدیل به      │  تیم فنی
│  قالب‌های       │  (مولتی‌مدیا، گرافیک، ویدیو)
│  دیجیتال       │
└───────┬────────┘
        ▼
┌────────────────┐
│  بارگذاری در   │  تیم فناوری
│  LMS           │
└───────┬────────┘
        ▼
┌────────────────┐
│  تست و QC      │  تیم تضمین کیفیت
│  (Quality Check)│
└───────┬────────┘
        ▼
┌────────────────┐
│  انتشار نهایی   │  مدیر سیستم
└────────────────┘
```

## استانداردهای تولید

### ویدیوهای آموزشی

| پارامتر | مقدار استاندارد |
|---------|----------------|
| وضوح | ۱۰۸۰p (Full HD) |
| فرمت | MP4, H.264 |
| نرخ فریم | ۳۰ fps |
| نسبت ابعاد | ۱۶:۹ |
| حداکثر طول | ۲۰ دقیقه |
| زیرنویس | فارسی (SRT) |
| کیفیت صدا | ۴۴۱۰۰ هرتز، ۱۲۸ kbps |

### اسلایدها

- **قالب:** استاندارد NTM (فایل PPTX مادر)
- **فونت:** وزیری‌متن (متن)، وزیری (عنوان) — اندازه ۱۸-۲۴
- **رنگ‌ها:** پالت NTM (آبی تیره #1A365D، طلایی #D4A843، سبز #2D8A4E)
- **حداکثر اسلاید:** ۱۵ اسلاید در هر ۹۰ دقیقه
- **نسبت متن به تصویر:** ≥ ۳۰٪ تصویر

### تصاویر و گرافیک

- **فرمت:** PNG (ترجیح) / JPG
- **رزولوشن:** حداقل ۷۲۰p
- **مجوز:** استفاده از تصاویر مجاز (Creative Commons یا تولید داخلی)
- **سبک:** مینیمال و آموزشی، پرهیز از شلوغی

## قالب‌های تعاملی (H5P)

| نوع H5P | کاربرد |
|---------|--------|
| Flashcards | مرور سریع مفاهیم |
| Drag and Drop | دسته‌بندی و تطبیق |
| Fill in the Blanks | تکمیل جاهای خالی |
| Crossword | جدول کلمات متقاطع |
| Interactive Video | ویدیو با پرسش درون‌نما |
| Quiz (Question Set) | آزمون ترکیبی |
| Timeline | خط زمانی رویدادها |

## مدیریت حقوق دیجیتال (DRM)

- محتوای NTM تحت مجوز **Creative Commons Attribution-NonCommercial 4.0** منتشر می‌شود
- استفاده تجاری نیازمند مجوز کتبی از شورای علمی NTM است
- واترمارک NTM بر روی همه ویدیوها
- شناسه محتوای یکتا برای هر فایل
- لاگ دسترسی برای همه دانلودها
