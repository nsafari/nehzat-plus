## داشبورد مدیریتی

داشبورد مدیر NTM شامل:

| بخش | محتوا |
|------|-------|
| **پیشرفت کلی** | درصد تکمیل هر ماژول، تعداد فعالان |
| **عملکرد مربیان** | نمرات متربیان به تفکیک مربی |
| **کیفیت محتوا** | بازخورد متربیان، نمرات آزمون |
| **هشدارها** | افت مشارکت، کاهش نمرات، تاخیرها |
| **گزارشات** | PDF/Excel قابل دانلود |

## نظرسنجی دیجیتال خودکار

پس از اتمام هر ماژول، یک نظرسنجی ۵ سؤالی به صورت خودکار برای متربی ارسال می‌شود:

۱. **محتوای این ماژول چقدر مفید بود؟** (۱-۵)
۲. **مربی چقدر توانمند بود؟** (۱-۵)
۳. **محتوای دیجیتال چقدر کاربردی بود؟** (۱-۵)
۴. **چه پیشنهادی برای بهبود دارید؟** (متن آزاد)
۵. **آیا این ماژول را به دیگران توصیه می‌کنید؟** (بله/خیر)

## الگوریتم‌های پیشنهاددهنده هوشمند

سامانه NTM بر اساس داده‌های یادگیری، پیشنهادهای زیر را ارائه می‌دهد:

| پیشنهاد | مبنای تصمیم |
|---------|------------|
| **ماژول بعدی پیشنهادی** | مسیر یادگیری بهینه + نقاط ضعف |
| **منابع تکمیلی** | موضوعات کم‌نمره در آزمون |
| **گروه مطالعه همتا** | سطح مشابه + زمان مشترک |
| **دوره بازآموزی** | نمرات پایین در ارزیابی مجدد |
| **مسیر شتاب‌یافته** | نمرات عالی در پیش‌آزمون |
