## نحوه استفاده

1. **انتخاب منبع:** برای هر بخش از پروژه، فایل مرتبط را پیدا کنید
2. **انتخاب محتوا:** بیانات، آیات، ادعیه یا حکمت‌های مناسب را انتخاب کنید
3. **ذکر منبع:** با ذکر منبع دقیق در کد یا مستندات استفاده کنید
4. **لینک‌دهی:** از لینک‌های مستقیم برای مراجعه استفاده کنید

---

## نکات مهم

- تمام بیانات با ذکر منبع دقیق آورده شده‌اند
- لینک‌ها به سایت‌های رسمی و معتبر ارجاع داده شده‌اند
- برای استفاده رسمی، منابع اصلی را بررسی کنید
- ترجمه‌ها ممکن است نیاز به بازبینی داشته باشند
- برای استفاده تجاری، مجوزهای لازم را کسب کنید
