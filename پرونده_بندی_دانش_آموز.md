# پرونده‌بندی دانش‌آموز (Student Portfolio)
**مکتب‌های قرآنی حضرت علی اکبر (ع)**
**نسخه ۱.۰ - ۱۴۰۳**

---

## مقدمه

پرونده دانش‌آموز **مرکز ثقل ارزیابی غیرمستقیم** است. نه فقط بایگانی، بلکه **ابزار یادگیری، خودآگاهی و تصمیم‌گیری**. هر دانش‌آموز یک پرونده فعال، زنده و مالکیت‌محور دارد.

**اصول**: مالکیت دانش‌آموز، دسترسی والدین، محرمانه بودن، استفاده باسازنده.

---

## ۳. مدیریت پرونده (PORTFOLIO MANAGEMENT)

### ۳-۱. مالکیت و دسترسی (OWNERSHIP & ACCESS)

| نقش | سطح دسترسی | اقدامات مجاز |
|------|------------|-------------|
| **دانش‌آموز** | مالک کامل | مشاهده همه، افزودن Voice، انتخاب اشتراک‌گذاری |
| **مربی** | مشارکت‌کننده | افزودن Journey/Evidence/Growth/Support، نظر |
| **والدین** | مشاهده‌کننده | مشاهده Identity/Journey/Evidence/Growth/Legacy، افزودن Feedback |
| **مدیر مکتب** | نظارت | مشاهده همه، استخراج گزارش، تایید Legacy |
| **ارزیاب/منسق** | تحلیل | مشاهده بدون هویت (Anonymized) برای تحلیل برنامه |
| **سیستم** | بک‌اند | بک‌آپ، امنیتی، لاگ دسترسی |

### ۳-۲. چرخه حیات پرونده (LIFECYCLE)

```
ثبت‌نام (PORTFOLIO-01, 02)
      │
      ▼
ماهانه: Journey (03) + Evidence (04) + Voice (05)
      │
      ▼
هر ترم: Growth (06) + Support (07) به‌روزرسانی
      │
      ▼
پایان سال: Legacy (08) تکمیل → بایگانی/انتقال به سال بعد
      │
      ▼
انتقال به حلقه/مکتب/مربی جدید → ادامه پرونده (بدون از دست دادن تاریخچه)
```

### ۳-۳. حفظ حریم خصوصی و امنیت

- **رمزنگاری**: AES-256 برای داده‌های حساس
- **لاگ دسترسی**: تمام ورودها ثبت می‌شود
- **حذف حق فراموشی**: دانش‌آموز/والدین می‌توانند حذف حساب درخواست دهند (با حفظ آرشیو قانونی)
- **مقررات**: مطابق قانون حمایت داده‌های شخصی ایران

## ۴. قالب دیجیتال (DIGITAL TEMPLATE)

### ساختار دیتابیس پیشنهادی

```sql
-- جداول اصلی
CREATE TABLE student_portfolio (
    student_id UUID PRIMARY KEY,
    identity JSONB,           -- PORTFOLIO-01
    baseline JSONB,           -- PORTFOLIO-02
    current_circle_id UUID,
    current_level CHAR(1),    -- S/N/F
    status VARCHAR(20),       -- active/graduated/transferred
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);

CREATE TABLE monthly_journey (
    id UUID PRIMARY KEY,
    student_id UUID REFERENCES student_portfolio,
    month DATE,               -- اول ماه
    attendance_pct DECIMAL,
    tajweed_score SMALLINT,
    hifz_score SMALLINT,
    samaa_pct DECIMAL,
    qiraat_score SMALLINT,
    behavior_notes TEXT,
    teacher_id UUID,
    created_at TIMESTAMP
);

CREATE TABLE audio_evidence (
    id UUID PRIMARY KEY,
    student_id UUID REFERENCES student_portfolio,
    month DATE,
    type VARCHAR(20),         -- tilawat/qiraat/hifz/samaa
    surah_topic VARCHAR(100),
    duration INTERVAL,
    file_path VARCHAR(500),
    quality_score SMALLINT,   -- 1-4
    created_at TIMESTAMP
);

CREATE TABLE certificates (
    id UUID PRIMARY KEY,
    student_id UUID REFERENCES student_portfolio,
    cert_type VARCHAR(50),    -- hifz/tajweed/qiraat/akhlaq/samaa
    level VARCHAR(50),
    issuer VARCHAR(100),
    issued_at DATE,
    file_path VARCHAR(500)
);

CREATE TABLE support_log (
    id UUID PRIMARY KEY,
    student_id UUID REFERENCES student_portfolio,
    date DATE,
    type VARCHAR(30),         -- behavioral/counseling/academic
    description TEXT,
    action_taken TEXT,
    outcome TEXT,
    responsible UUID
);
```
